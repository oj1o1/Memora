How it works

01

Record decisions as they happen

Manually, via git hooks, or through AI extraction from conversations and diffs.

from memora.memory import MemoraMemory
mem = MemoraMemory()

mem.record(
  summary="Lower refund threshold to $50k",
  reasoning="Fraud spike in Q1 dataset",
  type="DECISION",
  tags=["fraud", "threshold"],
  agent="Rahul",
)
02

AI extracts structured memories

Paste a conversation log or commit diff. Memora auto-classifies into typed memories with reasoning.

# Auto-extract from agent conversations
results = mem.extract_and_store(
  text=conversation_log,
  project="refund-agent",
) # Returns 3-8 typed memories
03

Query and trace decisions

Search, filter by type, ask natural language questions, or trace the lineage of how reasoning evolved.

# Natural language query
POST /api/why
{ "question": "Why did refund threshold change?" }

# Response includes AI-synthesized answer + related decisions

# pip install memora
from memora.antigravity_adapter import MemoraAdapter

adapter = MemoraAdapter(project="refund-agent", agent="Rahul")

# Record typed decisions
adapter.on_decision(
  "Lower threshold to 50k",
  reasoning="Fraud spike in dataset",
  type="DECISION",
  tags=["fraud", "threshold"],
)

# Auto-extract from conversations
adapter.on_conversation_end(messages)

context = adapter.get_context("threshold policy")

5 Memory Types

Structured extraction that captures what matters.

DECISION An architectural or implementation choice that was made
REJECTED An approach tried or considered and discarded — always includes why
NEXT Something left incomplete or planned for the next session
BUG_FIXED A bug that was found and resolved
CONTEXT Important context a new developer must know
